# Introduction to programming

Learn to build, test and explain your own programs. Choose your group below and open the lesson you are working on.

## Beginner: MakeCode Arcade

Create games with the **Blocks editor**. Start with characters, movement and button events, then explore coordinates, collecting treasure, score and simple game rules. The first eight lessons finish with a small game showcase.

- [Week 1: Talking character]({{ '/beginners/week-1.html' | relative_url }})
- [Week 2: Character controls and testing]({{ '/beginners/week-2.html' | relative_url }})

## Intermediate: Python

Write interactive text programs in **Python**. Practise variables, input, output and reusable functions, then build a shop, password checker and quiz while learning calculations, decisions and repetition. Finish the first eight lessons by improving and sharing a familiar project.

- [Week 1: Mission briefing generator]({{ '/intermediates/week-1.html' | relative_url }})
- [Week 2: Interactive greeting]({{ '/intermediates/week-2.html' | relative_url }})

Each lesson has a **Mission** and optional extensions. Build one small step, predict what will happen, test it, and explain your change. Save your work in the school-approved course folder and reopen the saved copy before finishing. Follow your teacher's starting point and pace; you do not need every extension.
